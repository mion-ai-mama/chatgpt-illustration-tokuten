# 写真から仕事に使えるイラスト＆デザインを作る ChatGPTプロンプト集

Instagramリールの視聴者に配布する、無料特典ページです。GitHub Pagesで公開できる
完全な静的サイトで、コードやビルド作業は一切不要です。

自分の写真をChatGPTへアップロードし、掲載しているプロンプトをコピーするだけで、
①写真を用途に合ったイラストへ変換する → ②完成したイラストをポスターやホームページ
などのデザインに展開する、という2段階を再現できます。

## 1. プロジェクト概要

- 4つの作例（カフェ／マルシェ／不動産／ブログ）を通じて、写真をイラスト化し、
  ポスター・フライヤー・ホームページ・ブログ素材へ展開する方法を紹介するページです。
- 合計8本のメインプロンプト（写真→イラスト用×4、イラスト→デザイン用×4）と、
  3本の修正用プロンプトに、それぞれコピーボタンが付いています。
- 他の特典ページ群（`instagram-tokuten-template`系列）と異なり、`js/content.js`
  のようなコンテンツ分離ファイルは使わず、文章・プロンプトはすべて `index.html`
  に直接書かれています（JavaScriptを無効にしてもプロンプト本文が読めるようにする
  ための設計です）。

---

## 2. ローカルでの確認方法

1. このフォルダをパソコンにダウンロード（またはクローン）する
2. `index.html` をダブルクリックしてブラウザで開く

サーバーを立てて確認したい場合は、フォルダの中で以下を実行してください。

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開くと確認できます。

## 3. 文章・プロンプトを変更する場所

すべて `index.html` の中に直接書かれています。変更したい文章やプロンプトを
テキストエディタで探して書き換えてください。

- プロンプト本文は `<pre class="prompt-card__text" id="...">〜</pre>` の中に
  書かれています。コピーボタンはこの `id` を参照しているため、`id` 自体は
  変更しないでください。
- 見出しや説明文は、その前後にある `<h2>` `<h3>` `<p>` タグの中の文章を
  書き換えてください。
- 色やフォント、余白などのデザインを変更したい場合は `style.css` の中の
  `:root { }` を編集してください（色は `#` から始まるコードです）。

## 4. 画像の差し替え方法

`assets/` フォルダに、以下のファイル名で画像を追加してください。ファイルを
置くだけで、`index.html` 側の編集は不要です（同じファイル名を指定済みのため）。

| ファイル名 | 内容 |
|---|---|
| `cafe-photo.jpg` | 作例1：カフェの元写真 |
| `cafe-illustration.jpg` | 作例1：フラットイラストへ変換した画像 |
| `cafe-poster.jpg` | 作例1：ポスターに展開した画像 |
| `market-photo.jpg` | 作例2：マルシェの元写真 |
| `market-illustration.jpg` | 作例2：ガッシュ風イラストへ変換した画像 |
| `market-flyer.jpg` | 作例2：フライヤーに展開した画像 |
| `living-photo.jpg` | 作例3：リビングの元写真 |
| `living-miniature.jpg` | 作例3：建築ミニチュアへ変換した画像 |
| `realestate-web.jpg` | 作例3：不動産ホームページに展開した画像 |
| `woman-photo.jpg` | 作例4：人物の元写真 |
| `woman-watercolor.jpg` | 作例4：線画＋水彩イラストへ変換した画像 |
| `blog-eyecatch.jpg` | 作例4：ブログのアイキャッチに展開した画像 |

画像がまだ無い間は、薄いベージュの背景にファイル名が表示される仮表示になり、
レイアウトは崩れません。画像を追加すると自動的に差し替わります。

## 5. OGP画像と公開URLの変更箇所

- OGP画像（SNSでシェアされたときに表示される画像）は `assets/ogp.jpg` を
  参照する設定になっていますが、**このファイルはまだ用意されていません**。
  画像を用意したら `assets/ogp.jpg` という名前で置いてください。
- 公開URLを変更する場合（別のリポジトリ名で公開する場合など）は、
  `index.html` の `<head>` 内にある以下の3箇所を、実際の公開URLに書き換えてください。
  - `<link rel="canonical" href="...">`
  - `<meta property="og:image" content="...">`（`assets/ogp.jpg`への絶対URL）
  - `<meta property="og:url" content="...">`

## 6. GitHub Pagesで公開する方法

1. GitHubでこのリポジトリを開く
2. 上部メニューの「Settings」→ 左メニューの「Pages」を開く
3. 「Build and deployment」の「Source」で「Deploy from a branch」を選ぶ
4. 「Branch」で「main」と「/ (root)」を選び、「Save」をクリックする
5. 数分待つと、ページ上部に公開URLが表示される

> 💡 このリポジトリに変更をpushするたびに、GitHub Pagesは自動で更新されます。

## 7. 動作確認項目

- [ ] すべてのコピーボタンが正しいプロンプト本文（見出し・説明文を含まない）をコピーできる
- [ ] コピー成功時に「コピーしました！」、失敗時に「コピーできませんでした。文章を選択してコピーしてください」と表示される
- [ ] 375px幅のスマートフォン表示で横スクロールが発生しない
- [ ] 目次のリンクをクリックすると該当セクションへスムーズスクロールする
- [ ] 画像が未配置でもレイアウトが崩れず、ファイル名のプレースホルダーが表示される
- [ ] PCでは3枚比較画像が横3列、スマートフォンでは縦1列になる
- [ ] 長いプロンプトが折りたたまれず、スクロール枠内で全文を確認できる
- [ ] ブラウザのコンソールにエラーが出ていない

---

## 8. よくあるエラーと対処方法

| 症状 | 原因の可能性 | 対処方法 |
|---|---|---|
| フォントが変わらない | Google Fontsが読み込めない通信環境 | フォールバックフォントで表示されるため機能上は問題ありません |
| コピーボタンが反応しない | ページを`file://`で直接開いている | GitHub Pages公開後のURL（`https://`）で確認する |
| 画像が表示されない | ファイル名の大文字・小文字違い | `assets/` 内の実際のファイル名と `index.html` の記載を見比べる |
| 公開URLが404になる | GitHub Pagesの設定がまだ反映されていない | 数分待ってから再度アクセスする |

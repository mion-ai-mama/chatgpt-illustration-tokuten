# 要件定義書 — 写真から仕事に使えるイラスト＆デザインを作る ChatGPTプロンプト集

## 0. アーキ構成

- 確定アーキ: #6 WEBアプリ（決定論）
- 操作者: ブラウザのエンドユーザー（Instagramリール視聴者）
- AI本体(プロンプトY): なし（ページはすべて静的。プロンプトはユーザー提供の設計書から
  そのまま埋め込む運用）
- MCP: なし
- 自社DB: なし
- フロントUI: あり（このリポジトリそのものがフロントエンド全体）
- 動的変数: なし
- 種別: Web型（静的サイト。バックエンド・DB・ビルド工程なし）
- 配布: マイ専用（発信用GitHubアカウント mion-ai-mama 配下の個人リポジトリ）
- ホスティング: GitHub Pages（無料・静的ファイル配信のみ）

補足: `mion-ai-mama/instagram-tokuten-template`から「Use this template」で複製して
作成した1回限りの特典ページ。ユーザー提供の設計書
（`Claude_Code_特典ページ設計書.md`）に基づき実装しており、他の特典ページ群
（大人ピンク×アイボリー系、`js/content.js`によるコンテンツ分離）とはデザイン・
ファイル構成が異なる（設計書内で明示的に指定されているため）。

## 1. プロジェクト概要

- 成果目標: Instagramリールの視聴者に配布する特典資料を、GitHub Pages上の
  1ページ完結型LPとして提供する。
- 特典内容: 自分の写真をChatGPTへアップロードし、①用途に合ったイラストへ変換し、
  ②完成したイラストをポスター・フライヤー・ホームページ・ブログ素材へ展開する、
  という2段階のプロンプト集（4つの作例・8本のメインプロンプト＋3本の修正用
  プロンプト）。

## 2. 想定読者（ペルソナ）

- 40〜50代のAI初心者、デザイン経験がない人
- ChatGPTで画像を作ってみたい人、仕事・店舗・発信・クライアントワークに
  画像を活用したい人
- 難しい専門用語や細かな設定が苦手な人

## 3. ページ構成（1ページ構成・全14セクション）

| # | セクション | 内容概要 |
|---|---|---|
| 1 | OP画像 | メインビジュアル（2026-09-05追記。OGP画像として受領した画像をページ本体にも表示。画像内のタイトル・サブコピーと重複するテキストは削除） |
| 2 | ファーストビュー | 画像に含まれないリード文・架空名称の注意書き・目次へのボタン |
| 3 | 目次 | 全セクションへのページ内リンク（スムーズスクロール） |
| 4 | この特典でできること | 4つの価値提案カード |
| 5 | 基本の使い方 | STEP1〜3カード＋補足コールアウト |
| 6 | 作例1 | カフェ写真→フラットイラスト→ポスター（3枚比較＋プロンプトA/B） |
| 7 | 作例2 | 週末マルシェ→ガッシュ風イラスト→イベントフライヤー（同上） |
| 8 | 作例3 | リビング写真→建築ミニチュア→不動産ホームページ（同上） |
| 9 | 作例4 | 人物写真→線画＋水彩→ブログのアイキャッチ（同上） |
| 10 | うまく作るための共通ポイント | 5項目の番号付きリスト |
| 11 | 文字が崩れたときの対処法 | 修正用プロンプト3本（個別コピー） |
| 12 | 利用時の注意 | 注意事項ボックス |
| 13 | まとめ | まとめ文 |
| 14 | 最後の案内（CTA）＋フッター | 『AIマネタイズの教科書』LINE登録導線（シリーズ標準を追加）／© 表記 |

各作例セクションの内部構成（共通）: 作例番号・テーマ名 → 短い説明 →
「元の写真／イラストに変換／デザインに活用」の3枚比較（PC横3列・スマホ縦1列）→
プロンプトA（写真→イラスト）→プロンプトB（イラスト→デザイン）→今回入力した内容→
向いている用途。

## 4. データ設計概要

DBは使用しない。他の特典ページ群と異なり `js/content.js` によるコンテンツ分離は
採用せず、文章・プロンプトはすべて `index.html` に直接記述している
（設計書内でJavaScript無効時も全文読めることが明示的に要求されているため）。

## 5. 画像について

`assets/` 配下の作例写真・イラスト12枚およびOGP画像（`ogp.jpg`）は、2026-09-05に
ユーザーより受領し配置済み。OGP画像はページ最上部のOP画像セクションにも表示している
（画像内のタイトル・サブコピーと重複する`hero__eyebrow`/`hero__title`は削除済み）。
`<img>` の読み込み失敗時は `script.js` が薄い背景色＋ファイル名のプレースホルダーへ
自動的に差し替える仕組みは、将来的な画像差し替え時の保険として維持している。
外部サイトからの代替画像は使用していない。

## 6. セキュリティ要件

- 個人情報の入力フォームなし、認証機能なし、決済機能なし → 該当するセキュリティ対策は最小限
- HTTPS: GitHub Pagesは標準でHTTPS配信
- 外部リンク（LINE誘導ボタン等）は `rel="noopener"` を付与

## 7. 技術スタック

- HTML5 / CSS3 / Vanilla JavaScript（フレームワーク・ビルド工程なし）
- フォント: Google Fonts（Noto Serif JP / Noto Sans JP / Cormorant Garamond。
  読み込めない環境向けのフォールバックあり）
- ホスティング: GitHub Pages（`main` ブランチ / root）

## 8. 外部サービス一覧

| サービス | 用途 | 費用 |
|---|---|---|
| GitHub Pages | 静的サイトホスティング | 無料 |
| Google Fonts | 見出し用フォント配信 | 無料 |
| LINE公式アカウント | CTA「AIマネタイズの教科書」の登録導線（既存の導線をそのまま利用） | 既存のため対象外 |

## 9. AI設計

該当なし（AI本体Yなし）。ページ自体にAIのランタイム処理は含まれない。

## 10. デザイン仕様（設計書より）

- トーン: 温かく上品なライフスタイル誌風（近未来的なAI教材感を避ける）
- カラー: 背景`#FAF7F1`／メイン文字`#2F332F`／サブ文字`#696B64`／
  テラコッタ`#B86143`／セージグリーン`#78866B`／薄いベージュ`#E8DED0`／白
- 最大コンテンツ幅1120px、本文幅760〜820px、角丸12〜18px
- 既存の特典ページ群（大人ピンク×アイボリー系）とは意図的に異なる配色。
  ユーザー承認のうえ、標準CTAバナー（ピンク）のみそのまま流用している

## 11. コピー機能

- 対象: メインプロンプト8本＋修正用プロンプト3本（合計11個）
- 成功時: ボタン表記変更＋画面下部トースト「コピーしました！」
- 失敗時: トースト「コピーできませんでした。文章を選択してコピーしてください」＋
  対象テキストを自動選択（手動コピーの補助）
- `navigator.clipboard`が使えない環境向けに`document.execCommand('copy')`の
  フォールバックを実装
